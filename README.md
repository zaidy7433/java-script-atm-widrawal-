## 📌 About The Project

The **ATM Withdrawal System** is a beginner-friendly JavaScript project that simulates a basic ATM withdrawal process.

It takes the user's account balance and withdrawal amount as input, checks whether sufficient balance is available, and displays the remaining balance after a successful withdrawal.

## ✨ Features

- 💰 Enter Account Balance
- 💳 Enter Withdrawal Amount
- ✅ Check Available Balance
- ⚠️ Display Insufficient Balance Message
- 🧮 Calculate Remaining Balance
- ⚡ Simple JavaScript Logic

## 🛠️ Technologies Used

- HTML5
- JavaScript

## ⚙️ How It Works

1. User enters their account balance.
2. User enters the withdrawal amount.
3. JavaScript checks the available balance.
4. If the withdrawal amount is less than or equal to the balance, the withdrawal is successful.
5. Otherwise, an insufficient balance message is displayed.
